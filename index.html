Method and interpretation

Current English L4 names and definitions are encoded locally by BGE-M3 through Ollama, with the exact model digest recorded in network metadata. Dense 1,024-dimensional embeddings are L2 normalised. Cosine-weighted nearest-neighbour links define a graph. Weighted Louvain detects communities and ForceAtlas2 places nodes. Colours identify graph communities; node area reflects the sum of incident cosine weights (weighted degree). Labels summarise dominant existing L3 families, not new category assignments.

Application communities remain overlapping editorial lenses. Links and paths express semantic proximity, not causal propagation, probability or severity. Coordinates are exploratory layout units. Filtering never changes the original taxonomy.
